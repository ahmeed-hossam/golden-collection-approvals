# Golden Collection approval cycle

Approval rules, policy and tools for Marketing and CX & Live Ops spend requests.

## What's here

| Path | What it is |
| --- | --- |
| `CLAUDE.md` | Briefing Claude Code reads at the start of every session |
| `config/approval-rules.yaml` | The agreed rules: 4 value bands, FP&A triggers, media exception, roles |
| `policy/approval-cycle-policy.md` | The written policy with both approval flow diagrams |
| `policy/approval-cycle-policy.docx` | The same policy as a Word file |
| `workbooks/approval-bands.xlsx` | Bands, FP&A rules, media exception and an approval checker |

## Live tools
- **Request log:** [Golden Collection – Approval Requests](https://docs.google.com/spreadsheets/d/1okUZL6QAH3_m2b-KH1RNw52SZK-IQhMwtngyT_1CMeY/edit) (Google Sheet). People submit requests and each approver signs their own step; bands are edited on the Settings tab.

## Bands at a glance (EGP incl. VAT)

| Band | Range | Approval chain |
| --- | --- | --- |
| A | up to 25K | L1 Senior / Lead; FP&A post-reviews weekly |
| B | 25K–100K | L2 Dept Manager + FP&A fast check |
| C | 100K–500K | L2 Dept Manager + FP&A full review |
| D | above 500K | L2 + FP&A, then Strategy Analyst, then CEO |

FP&A signs regardless of amount for out-of-budget items, new vendors, contracts over 12 months, hiring and discounts beyond the price list. Payments above EGP 1.5M need Accounting and the CEO jointly.
